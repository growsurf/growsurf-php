# Security Policy

## Reporting Security Issues

GrowSurf maintains this SDK. If you believe you have found a security vulnerability in it, please report it to support@growsurf.com rather than opening a public issue.

## Responsible Disclosure

Please give us a reasonable amount of time to investigate and address the issue before making any information public. We appreciate the efforts of security researchers who help keep this SDK and the systems it talks to secure.

## Other GrowSurf Security Issues

For security issues in GrowSurf products or services that are not related to this SDK, contact support@growsurf.com as well.
